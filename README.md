# **Анализ банковских операций**
## Описание 
- Показывает несколько последних успешных банковских операций клиента
- Возможен фильтр по заданной валюте
- Генерация номеров банковских карт по шаблону 0000 0000 0000 0000
## Структура проекта
- src/masks.py - маскировка номера карты, счета
- src/widget.py - маскировка номеров, форматирование даты
- src/processing.py - фильтрация операций по состоянию
- src/generators.py - фильтрация транзакций по валюте и генерация номеров карт
- src/decorators.py - логирование функций
- tests - папка с тестами

## Установка
- Клонируйте репозиторий:
```git clone git@github.com:VolkovaSSS/pythonProject1.git```
- Установите зависимости:
```pip install -r requirements.txt```
## Использование
Для использования нужно запустить файл main.py
например: python main.py
### Зависимости
- Python 3.x
- requests = ">=2.25.1"
- flask = ">=2.0.1"
## Тестирование
При тестировании использовался фреймворк pytest
Тестами охвачены модули:
- masks
- widget
- processing
- generators
- decorators

Для запуска тестов выполните команду:
```sh
pytest --cov=src --cov-report=html
```
